# 2026-08-23

## 修复：GitHub Actions RPM 构建失败（CentOS 8 / smartctl-ps3stor）
- 现象：`.github/workflows/build-centos8-rpm.yml` 在 `rpmbuild -bb` 阶段失败，`##[error]Process completed with exit code 1`，原因是 `error: Installed (but unpackaged) file(s) found:`（列出 smartd、update-smart-drivedb、drivedb.h、/etc/smartd.conf、/usr/share/doc/smartmontools/* 等）。
- 根因：`smartctl-ps3stor.spec` 的 `%install` 用 `%make_install` 安装了整个 smartmontools 树，但 `%files` 只声明 smartctl 及 man page。
- 修复：在 `%install` 段（`%make_install` 之后）添加清理命令，删除 smartd、update-smart-drivedb、smartd 相关 man page、/etc/smartd.conf、/etc/smartd_warning.sh、`%{_datadir}/smartmontools`、`%{_docdir}/smartmontools`。
- 注意：该仓库在 Windows 上开发（core.fileMode=false），此前 workflow 已有 chmod +x configure/config.*/install-sh 等修复（commit 63d6c71 "fix(ci): 修复 RPM 构建 ./configure Permission denied"）。
- 验证：`%files` 中引用的 AUTHORS、smartctl_ps3stor_README 均存在于仓库根目录。
